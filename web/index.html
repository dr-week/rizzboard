30-SECOND SETUP

Install in Chrome, Brave, Edge, or Arc

  1. 1.

    Download & Extract Archive

    Download rizzboard-extension-v1.1.0.zip below and unzip it to a local folder on your machine.

  2. 2.

    Enable Developer Mode

    Navigate to chrome://extensions (or brave://extensions) and toggle Developer mode in the top-right corner.

  3. 3.

    Load Unpacked & Press Alt+R

    Click Load unpacked, select the unzipped folder, and open any web chat or click the RizzBoard toolbar icon.
